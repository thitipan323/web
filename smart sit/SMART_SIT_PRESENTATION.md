# Smart Sit — บทนำเสนอโปรเจกต์

## 1) เกริ่นขายของก่อนเลย (Hook)

เคยไหมครับ/คะ นั่งทำงานไม่นานก็เริ่มปวดคอ ปวดไหล่ และปวดหลัง
ปัญหานี้ดูเล็ก แต่สะสมทุกวันจนกระทบทั้งสุขภาพและประสิทธิภาพการทำงาน
วันนี้ทีมของเราขอเสนอ **Smart Sit** ผู้ช่วยดูแลท่านั่งแบบเรียลไทม์ ที่ช่วยเตือนก่อนอาการปวดจะเกิด

## 2) ทำเรื่องอะไร (Project Overview)

Smart Sit คือระบบตรวจจับท่านั่งจากกล้องเว็บแคมด้วย AI
โดยวิเคราะห์จุดสำคัญของร่างกาย เช่น ตาและไหล่ เพื่อดูความเสี่ยงของไหล่เอียง หลังค่อม หรือคอยื่น
หากผู้ใช้นั่งผิดท่าต่อเนื่องเกินเวลาที่กำหนด ระบบจะส่งสัญญาณเตือนทันที พร้อมบันทึกข้อมูลเหตุการณ์

## 3) วัตถุประสงค์ (Objectives)

- ช่วยลดพฤติกรรมการนั่งผิดท่าที่สะสมระยะยาว
- สร้างเครื่องมือเตือนท่านั่งที่ใช้งานง่ายในชีวิตประจำวัน
- ปรับค่าการตรวจจับให้เหมาะกับแต่ละคนผ่าน Calibration
- เก็บข้อมูลการแจ้งเตือนเพื่อวิเคราะห์พฤติกรรมการนั่งย้อนหลัง

## 4) ขอบเขต (Scope)

- ใช้งานบนคอมพิวเตอร์ที่มีกล้องเว็บแคม
- ตรวจจับท่านั่งจากภาพมุมหน้าผู้ใช้งานแบบเรียลไทม์
- ประเมินจากตัวชี้วัดหลัก เช่น Shoulder Tilt และระยะตา-ไหล่เทียบกับ Baseline
- แจ้งเตือนเมื่อผิดท่าต่อเนื่องตามเวลาที่ตั้งไว้
- บันทึก Log ลงไฟล์ CSV และ JSON
- ไม่ใช่ระบบวินิจฉัยทางการแพทย์

## 5) จุดเด่น (Highlights)

- **Real-time AI Monitoring**: ตรวจจับและเตือนทันทีระหว่างใช้งาน
- **Personal Calibration**: ปรับค่าอ้างอิงตามสรีระและมุมกล้องของแต่ละคน
- **ใช้งานง่าย**: มีปุ่ม Start / Stop / Calibrate ชัดเจน
- **Feedback ครบ**: มีทั้งภาพ Skeleton และเสียงแจ้งเตือน
- **เก็บข้อมูลต่อยอดได้**: มี Log สำหรับทำกราฟหรือรายงานภายหลัง

## 6) ข้อจำกัด (Limitations)

- ความแม่นยำขึ้นกับแสง คุณภาพกล้อง และมุมกล้อง
- ถ้ามีการบังตัวหรืออยู่นอกเฟรม อาจตรวจจับได้ไม่ครบ
- ใช้ทรัพยากรเครื่องระดับหนึ่งในการประมวลผลแบบเรียลไทม์
- เป็นระบบช่วยเตือน ไม่ใช่อุปกรณ์ทางการแพทย์

## 7) เทคโนโลยีที่ใช้ (ภาษา + โมเดลที่เรียกใช้)

### ภาษาและเครื่องมือหลัก

- **ภาษา**: Python
- **Computer Vision**: OpenCV (`opencv-python`)
- **AI Pose Detection**: MediaPipe Tasks
- **คำนวณเชิงตัวเลข**: NumPy
- **GUI**: CustomTkinter

### โมเดลที่เรียกใช้

- โปรเจกต์ใช้โมเดล **MediaPipe Pose Landmarker (lite)**
- ไฟล์โมเดล: `models/pose_landmarker_lite.task`
- รูปแบบการทำงาน: ตรวจจับ Landmark ของร่างกายในแต่ละเฟรม แล้วส่งค่าเข้า Logic เพื่อตัดสินว่าท่าทางปกติหรือผิดท่า

### หลักการคำนวณที่ใช้ในระบบ

- **Shoulder Tilt**: ตรวจผลต่างแกน Y ของไหล่ซ้าย-ขวา
- **Slouching / Forward Head**: เปรียบเทียบระยะตา-ไหล่ปัจจุบันกับ Baseline ที่ได้จาก Calibration
- ถ้าค่าผิดเงื่อนไขต่อเนื่องเกินเวลาที่กำหนด ระบบจะ Trigger Alert

## 8) สรุปปิดท้าย (Closing)

Smart Sit ไม่ได้แค่เตือนว่า “นั่งผิด” แต่ช่วยสร้างนิสัยการนั่งที่ดีอย่างต่อเนื่อง
เป้าหมายของโครงการคือทำให้การดูแลสุขภาพระหว่างทำงานเป็นเรื่องง่าย ใช้งานได้จริง และต่อยอดข้อมูลได้ในอนาคต

## 9) แผนใช้งานในบริษัท (เลือกทางที่ 1: ติดตั้งบนเครื่องแต่ละคน)

### แนวทางที่เลือก

- แจกแอปให้พนักงานติดตั้งบนเครื่องของตนเอง (Desktop App)
- ใช้กล้องของผู้ใช้แต่ละคน และประมวลผลบนเครื่องนั้นทันที
- ไม่จำเป็นต้องส่งภาพวิดีโอขึ้นเซิร์ฟเวอร์

### ทำไมเลือกแนวทางนี้

- เริ่มใช้งานได้เร็วที่สุด
- ความเป็นส่วนตัวสูงกว่า เพราะข้อมูลภาพไม่ออกนอกเครื่อง
- ลดภาระโครงสร้างพื้นฐานฝั่งเซิร์ฟเวอร์

### วิธีปรับระบบให้รองรับหลายคนในบริษัท

- แพ็กแอปเป็นไฟล์ติดตั้ง (เช่น `.exe`) เพื่อแจกผ่าน IT
- ตั้งค่าเริ่มต้นส่วนกลาง เช่นค่า Threshold และเวลาแจ้งเตือน
- ออกแบบโฟลเดอร์ Log มาตรฐานต่อผู้ใช้ เพื่อให้ทีมสามารถรวมผลภายหลังได้
- ทำคู่มือใช้งานสั้น: Start → Calibrate → Monitoring

### แผน Rollout ที่แนะนำ

- **Phase 1 (Pilot):** ทดสอบกับ 10-20 คน เป็นเวลา 2-4 สัปดาห์
- **Phase 2 (Improve):** ปรับค่าเตือนจาก feedback และลด false alert
- **Phase 3 (Scale):** ขยายทั้งบริษัท พร้อมแพ็กเกจติดตั้งเวอร์ชันเสถียร

### KPI เบื้องต้นที่วัดผลได้

- อัตราการใช้งานต่อวัน (Daily Active Users)
- จำนวนการแจ้งเตือนเฉลี่ยต่อคนต่อวัน
- แนวโน้มการลดลงของการนั่งผิดท่าหลังใช้งาน 2-4 สัปดาห์
